DESCRIÇÃO DOS MÉTODOS DA CLASSE Calculadora_202321250034

1. public double soma(double num1, double num2)
   - Descrição: Recebe dois números de ponto flutuante (double) como parâmetros
     e retorna a soma do primeiro número com o segundo.

2. public double sub(double num1, double num2)
   - Descrição: Recebe dois números de ponto flutuante (double) como parâmetros
     e retorna a subtração do primeiro pelo segundo.

3. public double mult(double num1, double num2)
   - Descrição: Recebe dois números de ponto flutuante (double) como parâmetros
     e retorna o produto da multiplicação entre eles.

4. public double div(double num1, double num2)
   - Descrição: Recebe dois números de ponto flutuante (double) como parâmetros
     e retorna o resultado da divisão do primeiro pelo segundo. Caso o divisor
     (num2) seja igual a zero, exibe uma mensagem de aviso no terminal indicando
     "Aviso: Divisão por zero" e retorna 0.
